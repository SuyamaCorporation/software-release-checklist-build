# Software Release Deployment Checklist Build

A customizable pre-deployment checklist with six standard sections covering Code Review, Tests Passing, Documentation Updated, Rollback Plan, Stakeholder Sign-off, and Environment Config. Check off items, add custom items to any section, track overall completion percentage, and export the full checklist as Markdown.

## Features

- Six pre-built deployment sections with common checklist items
- Check/uncheck items with live progress bar and completion percentage
- Add custom items to any existing section
- Export full checklist as Markdown with copy-to-clipboard support
